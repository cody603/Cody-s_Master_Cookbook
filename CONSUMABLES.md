# Consumables — the repeat-buy log

**This is not the cookbook, and it isn't a recipe list.** It is the short list of things this house buys over and over on its own rhythm — drinks above all — plus **when each was last bought**, so a chat session can say *"it's been a week since the Zevia, are you low?"* instead of waiting to be told.

Cody, 2026-09-14: *"I'd like you to say — hey, it's been a week, you know, and you've cooked this and this and this. Are you low on Zevia? … I think we're missing drinks and the necessity of drinks in our system. Obviously that's kind of separate than the actual cookbook."* He's right that it was missing; this file is the fix.

## How it works

- **A chat session reads this file when planning a week or building a grocery list**, and **asks about anything past its interval.** It asks — it doesn't add things silently.
- **Chat may write to this file directly**, with no approval needed: stamping a new *last bought* date, or adding an item someone says they buy regularly. It's a shopping log, not the book. *(Anything that would change a **recipe** still goes through `PROPOSED-REVISIONS.md`.)*
- **Stamp the date when a shopping run actually happens** — when the cart is filled or the list is handed off — not when the item is merely discussed.
- **Intervals here are observed, not prescribed.** Where one is unknown, it says so. Don't invent one; watch a few cycles and write down what's real.

## What does not go here

- **Ingredients for a specific dish** — those come off that recipe's own Grocery Shopping List when the dish is planned.
- **Non-recipe foods that aren't on a clock** — fruit, snacks, sandwich fixings. Those are `HOUSEHOLD-STAPLES.md`.
- **Anything about a recipe** — quantities, methods, ratings. Those are `PROPOSED-REVISIONS.md`.

## An honest limit

**Nothing here can reach out to anyone.** A chat session has no background process and cannot send a reminder on its own. **The check happens when someone starts a conversation** — planning a week, building a list, asking what's for dinner. That is when this file gets read and the question gets asked. If nobody opens a chat for three weeks, nobody gets asked about the Zevia.
