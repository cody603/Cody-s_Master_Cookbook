# Household Staples — groceries that aren't recipes

**This is not the cookbook either.** Cody's rule for what goes where, 2026-09-12: *"Quick pickles should go into the family cookbook because quick pickles is a great addition and something that requires cooking. Cottage cheese and all that stuff should be a side that is non-cooked items, doesn't go in a cookbook, but should be included into the refrigerator list along with the staple sides and the staple meals."* And: *"She says, well, I want to add sandwiches — that wouldn't go in a cookbook, it would just go as a quick staple thing that we need for groceries and meal planning… we buy extra fruit, or we buy Nutella and croissants. Does that really go in a cookbook? Not necessarily, but it is something that could be on the refrigerator list for that week."*

**So: if it needs cooking, it's a recipe and belongs in `codys-cookbook.md`. If it doesn't, it lives here.** When a week is planned, the chat pulls from this file after the recipes' own lists — *"anything extra this week?"*

**Additions come through `PROPOSED-REVISIONS.md`, like everything else.** Cody, 2026-09-12: *"we're buying Nutella a lot and it's not one of our staple grocery list items, can we add that? — I have put that down as a revision request. When Cody approves it, it will be implemented."* So a chat session doesn't edit this file; it files the request, Cody approves, and a Code session adds the line here with the date and who asked.
