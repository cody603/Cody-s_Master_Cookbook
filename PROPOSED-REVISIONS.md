# Proposed Revisions — the intake queue

**This is not the cookbook.** It is where anyone using the cookbook from chat — Vicky, the kids, a chat session Cody is running himself — writes down something that *should* change in the book, without changing the book. Cody, 2026-09-12: *"I don't want her revising the code completely… I'd like that to be noted in a proposed revisions log that's proposed by somebody else."*

**How it moves:** a chat session appends an entry under **Open** (or emails it to Cody in the same format if it can't write here). A Claude Code session reads this file at the start of every session, reviews the open entries with Cody, makes the change in `codys-cookbook.md` for the ones he approves, and moves the entry to **Done** or **Declined** with the date and a one-line outcome. **Cody's own entries can be applied directly; everyone else's wait for his OK.**

**What belongs here:** anything that would change a recipe or a rule — an ingredient that isn't at Walmart and what was bought instead, a substitution that worked (or didn't), a quantity that was wrong, a step that needed a note, a new recipe someone wants written up, a dish someone wants on or off the fridge sheet. **What doesn't:** plain groceries that aren't recipes (fruit, snacks, sandwich fixings) — those go in `HOUSEHOLD-STAPLES.md` and need no approval.

**Format — one entry, newest first, never edit someone else's entry:**

```
### 2026-09-12 · Vicky · §7.150 Grilled Salmon with Avocado Salsa
**What happened:** Walmart didn't have serrano peppers; used one jalapeño instead and it was fine.
**Proposed change:** note jalapeño as the in-store substitute on the ingredient line.
**Suggested by chat:** add it as a labeled substitute under CLAUDE.md §3e, don't alter the source's line.
```
