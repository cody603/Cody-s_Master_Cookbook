# photos/ — pictures of the dishes, for the printed cookbook

Cody is taking photos of what gets cooked, for a printed cookbook that comes later (see `CLAUDE.md` §9). They live here.

**Naming: one file per dish, named by the recipe's anchor**, exactly as it appears in the cookbook's links — so the photo can be matched to its entry without guessing:

```
photos/3-darcys-steak.jpg
photos/69-codys-pulled-pork.jpg
photos/115-easy-caulimash-keto-mashed-potatoes.jpg
```

A second shot of the same dish gets a suffix: `3-darcys-steak-2.jpg`. A whole plated night (the steak *with* the caulimash and sprouts) is named for the main, with `-plate`: `3-darcys-steak-plate.jpg`.

**How they get here:** dropped into this folder in a Code session, or emailed to Cody's address with the dish named — a Code session files and renames them. Chat sessions do not write here.

**Nothing is generated from this folder yet.** When the printed cookbook is built, each recipe picks up its photo by anchor. Until then this is just a tidy place to keep them.
