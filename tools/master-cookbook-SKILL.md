Whenever I mention my cookbook in any form — read my cookbook, pull my cookbook, add this to my cookbook, or something casual like "in my cookbook I had some pho" — always read the live cookbook from my GitHub repo before responding. There is one master cookbook and it lives in that repo. Never rely on memory or an old copy, and never ask me to upload it.

Repo: https://github.com/cody603/Cody-s_Master_Cookbook

**Do not fetch `codys-cookbook.md` itself — it is over 4 MB and a fetch never gets past the front matter.** Read the generated `planner/` folder instead, which is the same book split one entry per file and rebuilt with every change. Raw URL pattern:

`https://raw.githubusercontent.com/cody603/Cody-s_Master_Cookbook/main/planner/<path>`

- `planner/meal-planning-sheet.md` — the fridge sheet. Fetch this first, every time.
- `planner/staples.md` — every ⭐ Staple with its badge and ⏰ Countdown to dinner line.
- `planner/index.md` — every entry on one line, to look a dish up by name.
- `planner/recipes/<anchor>.md` — the full recipe; the anchor is the one the sheet links to.
- `planner/recipes/t111-planning-a-week--the-conversation-mode-workflow.md` — **the workflow for planning a week. Read it and follow it exactly** when I give you days, dinner times, and dishes.

When I plan a week, the deliverables in order are: (1) the grocery list, merged by store, pushed to my phone's Reminders; (2) calendar events for every countdown stage of every dish, placed backward from the dinner time I give — dry brine the day before, sous vide two days before, light the smoker, start prep — plus the dinner itself; (3) one document with every recipe's ingredients and cooking instructions for the whole week, verbatim from the cookbook, downloadable and sent through Gmail; (4) then answer my questions while I cook, from the recipe file, not from memory. Read my plan back as a table before building anything, and show me the calendar event table before writing it.

Every temperature in the cookbook is Fahrenheit. Memphis Dust is never on my grocery list — I keep a stash. If I change a recipe while cooking, write the change down with the date so the next Code session can put it in the master file; you do not edit the book from chat.
